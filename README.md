# Heart Disease Risk Analysis Using R

## 1. Introduction

Heart Disease Risk Analysis Using R is a mini project developed using the R programming language. The main purpose of this project is to analyze heart disease data and understand the relationship between different health-related factors.

The project uses data analysis, data cleaning, statistical calculations, data visualization, and logistic regression to study heart disease records.

## 2. Objectives

- To analyze heart disease data using R.
- To clean and prepare the dataset.
- To calculate basic statistical values.
- To visualize data using different graphs.
- To study relationships between health-related variables.
- To use logistic regression for educational classification.

## 3. Technologies Used

- **Programming Language:** R
- **IDE:** RStudio
- **Libraries:** ggplot2, caret
- **Dataset:** Heart Disease Dataset

## 4. Dataset Description

The dataset contains information about different health-related factors, including:

- Age
- Sex
- Chest pain type
- Resting blood pressure
- Cholesterol level
- Maximum heart rate
- Exercise-induced angina
- ST depression
- Heart disease target category

The `target` column represents the outcome category in the dataset.

## 5. Project Features

- Data loading and exploration
- Data cleaning
- Statistical analysis
- Histogram visualization
- Bar chart and pie chart
- Boxplot analysis
- Scatter plot analysis
- Analysis of cholesterol and age
- Logistic regression classification
- Model accuracy evaluation

## 6. Installation Requirements

Install the following software:

1. R
2. RStudio

Install the required R packages by running:

```r
install.packages("ggplot2")
install.packages("caret")
```

## 7. How to Run the Project

1. Download or clone this repository.
2. Open RStudio.
3. Open the `heart_disease_analysis.R` file.
4. Install the required packages.
5. Run the R script.
6. View the analysis results and graphs in RStudio.

The project downloads the dataset from the following source:

`https://raw.githubusercontent.com/sharmaroshan/Heart-UCI-Dataset/master/heart.csv`

An active internet connection is required to download the dataset using this URL.
